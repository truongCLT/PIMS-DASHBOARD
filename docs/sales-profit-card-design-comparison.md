# 매출·손익 카드 디자인 비교

비교 대상은 메인 대시보드 같은 행의 `매출 실적 및 전망` 카드와 `손익현황` 카드다. 데이터 계산과 UI는 변경하지 않았으며, 현재 구현과 실행 화면을 기준으로 차이와 권장안을 정리했다.

## 화면 확인

- 데스크톱 1440px: [비교 화면](../screenshots/sales-profit-comparison-desktop.jpg)
- 좁은 화면 1024px: [비교 화면](../screenshots/sales-profit-comparison-narrow.jpg)

1440px에서는 두 카드 모두 한 행에 안정적으로 배치된다. 1024px에서는 고정된 오른쪽 330px 카드 때문에 매출·손익 카드가 각각 약 220px까지 좁아지며 다음 문제가 나타난다.

- 매출 카드 제목이 두 줄로 분리되고 `단위`, `상세보기`, 범례 문구도 글자 단위로 줄바꿈된다.
- 매출 값 라벨이 겹치고 일부 월만 축 라벨이 보인다.
- 손익 카드 범례는 상대적으로 덜 깨지지만 차트와 축 글자가 지나치게 작아진다.
- 두 카드가 같은 폭이어도 매출 카드는 세로로 길고 복잡하게, 손익 카드는 중앙에 작게 축소되어 시각적 균형이 달라진다.

## Aqua Glass 기준 평가

### 일치하는 요소

- 카드 배경 `#ffffff`, 테두리 `#e2e9f3`, 제목 `#16294a`, 링크 `#2f7cf6`, 보조 글자 `#7c8ba3`는 Aqua Glass 색상 토큰과 일치한다.
- 차트의 파랑·청록 계열은 `chart1`, `chart2` 역할과 일치한다.
- 4px 배수 중심의 간격은 디자인 시스템의 기본 spacing step과 대체로 맞는다.

### 불일치 또는 관리 위험

- 두 카드에 동일한 색상·패딩이 직접 반복되어 있고 한 카드는 토큰 상수, 다른 카드는 hex 값을 사용한다.
- 공통 UI 토큰은 카드 모서리 8px, 제목 16px을 정의하지만 두 차트 카드는 6px와 12~13px을 사용한다.
- Aqua Glass의 기본 radius는 1rem이지만 밀도가 높은 운영 대시보드에는 그대로 적용하기 어렵다. 차트 카드용 compact 규칙을 별도 합의해야 한다.
- 손익 툴팁은 SVG 좌표와 글꼴을 별도로 계산해 공통 팝오버·툴팁 규칙을 적용하기 어렵다.

## 권장안

### 즉시 통일 권장

1. **헤더 타이포그래피**
   - 제목 13px / 600
   - 단위 11px / 400
   - 상세보기 12px / 400
   - 헤더 하단 간격 8px
   - 제목·단위 영역에는 `min-width: 0`, 상세보기에는 `white-space: nowrap` 적용

2. **범례 기본 규격**
   - 글자 11px 또는 12px 중 하나로 통일한다. 현재 카드 밀도를 고려하면 11px이 안전하다.
   - 아이콘과 문구 간격 4px, 항목 간격 10~12px을 공통 규칙으로 둔다.
   - 좁은 폭에서는 단어 중간 줄바꿈을 금지하고 항목 단위로 다음 줄로 넘긴다.

3. **상태와 빈 화면**
   - 빈 상태 글자 12px, 카드 가용 높이 중앙 정렬로 통일한다.
   - 로딩·데이터 없음·오류의 색과 문구 계층을 같은 규칙으로 사용한다.

4. **좁은 화면 레이아웃**
   - 1024px 전후에서는 세 카드 고정 3열을 유지하지 말고, 수주 카드를 다음 행으로 이동하거나 차트 두 개에 최소 폭을 부여한다.
   - 매출 카드 제목·범례·상세보기는 단어 중간에서 분리되지 않아야 한다.

### 현행 유지 권장

- 매출의 계획·실적·전망 표시와 손익의 누적 이익 구조는 데이터 의미가 다르므로 같은 차트 형태로 통일하지 않는다.
- 매출 달성률 칩과 손익 영업이익·이익률 표시는 지표 목적이 다르므로 각각 유지한다.
- 상세 모달은 이미 공통 컴포넌트를 사용하므로 데이터 컬럼만 다르게 유지한다.
- 테마별 차트 색상은 의미 구분이 유지되는 범위에서 현행 테마 설정을 따른다.

### 추가 검토

- 손익 SVG 툴팁을 매출 카드와 같은 HTML 오버레이 패턴으로 바꿀지 검토한다. 접근성, 좁은 화면 가독성, 유지보수에는 유리하지만 차트 구현 변경 범위가 크다.
- 차트 카드 전용 `compact card header` 규칙을 Aqua Glass 또는 제품 공통 컴포넌트로 정의할지 검토한다. 일반 콘텐츠 카드의 16px 제목·큰 radius를 그대로 적용하는 것은 현재 정보 밀도와 맞지 않는다.

## 우선순위

1. **높음:** 1024px에서 카드 최소 폭과 행 재배치
2. **높음:** 헤더 제목·단위·상세보기·줄바꿈 규칙 통일
3. **중간:** 범례 글자와 항목 간격 통일
4. **중간:** 빈 상태 표현 통일
5. **낮음:** 두 툴팁의 구현 방식과 외형 통일

## 결론

두 카드는 차트 내용 자체를 같게 만들 필요는 없다. 가장 큰 문제는 데이터 표현 차이가 아니라, 같은 역할의 헤더·범례·빈 상태가 서로 다른 크기와 간격을 사용하고 좁은 화면에서 레이아웃이 깨지는 점이다. 우선 공통 헤더와 반응형 배치를 통일하고, 차트 본체는 지표별 표현을 유지하는 방향이 적절하다.
