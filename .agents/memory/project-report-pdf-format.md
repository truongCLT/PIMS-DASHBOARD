---
name: Project report PDF format
description: Required branding and page layout for exported monthly project reports.
---

Monthly project-report PDFs must use the DAEWOOVINA brand, omit visible generated dates and report year/month from the PDF header, and place all report sections on one landscape A4 page. The filename may retain year/month for identification.

**Why:** The report is distributed as a standardized single-page management document. Visible dates in the generated header and the former DAEWOO E&C name do not match the required format.

**How to apply:** Capture the complete report as one page target and scale it proportionally within the A4 margins. Keep every section visible without clipping; do not restore per-section PDF pages or date-bearing headers.
