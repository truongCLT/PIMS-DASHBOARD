# 대시보드 디자인 패턴 변경 요청

## ⚠️ 최우선 원칙 (반드시 준수)
아래 항목은 **절대 변경하지 마세요**:
- 데이터 표시 형태 (숫자, 텍스트, 값의 종류와 위치)
- 레이아웃 구조 (카드 배치 순서, 그리드 컬럼 수, 섹션 순서)
- 지표(KPI) 종류와 개수
- 차트 종류 (라인 차트는 라인 차트로, 도넛 차트는 도넛 차트로 유지)
- 컴포넌트 계층 구조 (어떤 정보가 어떤 카드 안에 있는지)

**오직 시각적 디자인(색상, 타이포그래피, 카드 스타일, 여백, 그림자, 아이콘 스타일)만 변경**하는 작업입니다. 즉, 기존 대시보드의 "뼈대"는 그대로 두고 "피부"만 새로 입히는 작업이라고 생각해주세요.

---

## 적용할 디자인 시스템

### 1. 컬러 팔레트 (CSS 변수로 정의 후 전역 적용)
```css
--color-primary-navy: #1a2744;      /* 헤더, 강조 카드 배경 */
--color-primary-blue: #4a7fd4;      /* 메인 데이터 색상, 버튼, 링크 */
--color-accent-coral: #f0876b;      /* 보조 데이터, 두 번째 차트 시리즈 */
--color-success-green: #4caf82;     /* 증가/긍정 지표 */
--color-background: #f4f6fa;        /* 페이지 배경 */
--color-card-bg: #ffffff;           /* 카드 배경 */
--color-text-primary: #1a2744;      /* 본문 진한 텍스트 */
--color-text-secondary: #8b96ab;    /* 라벨, 보조 텍스트 */
--color-border: rgba(0,0,0,0.04);   /* 최소한의 구분선 */
```
기존 컴포넌트에서 사용 중인 색상들을 위 팔레트로 전면 치환해주세요. 파란색 계열이 전체의 70~80%를 차지하고, 코랄/오렌지는 보조 강조색으로만 사용합니다.

### 2. 타이포그래피 규칙
- KPI 숫자(핵심 지표 값)는 **크고 굵게** (font-size: 32~40px, font-weight: 700)
- 해당 숫자 위/아래의 라벨은 **작고 옅게** (font-size: 12~13px, color: var(--color-text-secondary))
- 이 "작은 라벨 + 큰 숫자" 조합을 모든 KPI 카드에 동일하게 적용

### 3. 카드 스타일
```css
border-radius: 14px;
box-shadow: 0 2px 12px rgba(0,0,0,0.05);
border: none; /* 테두리 대신 그림자로 분리 */
padding: 20~24px;
```
- 카드 중 1개(가장 강조하고 싶은 지표)는 다크 네이비 배경(`--color-primary-navy`)에 흰 텍스트로 처리해 시각적 포인트를 줍니다.

### 4. 차트 색상 통일
- 모든 차트(라인, 바, 도넛, 게이지)는 위 팔레트의 blue/coral 두 색만 사용
- 라인/영역 차트는 하단에 옅은 그라데이션 채우기 추가
- 바 차트는 막대 상단 모서리를 라운드 처리
- 도넛/게이지 차트는 중앙에 큰 폰트로 퍼센트 숫자 배치

### 5. 배지·태그 스타일
- 상태값(증감, 카테고리 등)은 알약형(pill) 배지로 표시
- 배경은 해당 색상의 옅은 버전(예: 그린이면 rgba(76,175,130,0.12)), 텍스트는 진한 버전

### 6. 버튼
- Primary 버튼: `--color-primary-blue` 배경, 흰 텍스트, border-radius 8px
- Secondary 버튼: 옅은 배경 또는 아웃라인, 텍스트는 navy

### 7. 아이콘
- 라인 아이콘 스타일로 통일, 원형 배경(옅은 blue tint) 안에 감싸서 배치

---

## 요청사항
현재 대시보드 코드에서 위 디자인 시스템을 전역 스타일(CSS 변수 또는 테마 파일)로 먼저 정의한 뒤, 기존 컴포넌트들이 이 변수를 참조하도록 리팩토링해주세요. **데이터 바인딩 로직, 컴포넌트 구조, 레이아웃 그리드는 절대 건드리지 말고 스타일링 레이어만 교체**하는 방식으로 진행해주세요.

작업 전, 변경 범위에 대해 궁금한 점이 있으면 먼저 질문해주세요.
