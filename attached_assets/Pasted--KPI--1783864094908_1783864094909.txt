컴포넌트의 레이아웃, 컴포넌트 구조, 표시되는 지표(KPI), 데이터 표현 형태(차트 종류, 테이블 구성), 각 요소의 배치 위치는 절대 변경하지 마세요.
오직 시각적 디자인(색상, 타이포그래피, 여백, 모서리, 그림자, 아이콘 스타일)만 아래 스타일 가이드에 맞춰 교체해 주세요.

**중요 — 코드 작성 방식 규칙**
- 이 프로젝트는 컴포넌트 스타일을 React `style={{ ... }}` 인라인 객체로 작성하고, 색상 값은 `src/index.css`에 정의된 CSS 변수(`var(--color-...)`)를 참조하는 방식(Dashboard 3와 동일한 패턴)을 사용합니다. Dashboard 4에도 동일한 패턴을 적용해 주세요.
- 새로운 색상을 추가할 때는 하드코딩된 hex 값을 인라인 스타일에 직접 쓰지 말고, `src/index.css`에 CSS 변수로 먼저 선언한 뒤 `var(--color-...)` 형태로 참조하세요. (예: `--color-primary-blue`, `--color-navy-dark`, `--color-sky-light` 등)
- Tailwind CSS는 프로젝트에 설치만 되어 있고 실제 화면에서는 사용하지 않는 방식을 유지 중이므로, 새로 Tailwind 클래스를 도입하지 말고 기존 인라인 스타일 + CSS 변수 패턴을 그대로 따라 주세요.
- CSS 변수는 한 곳(index.css)에서 값을 바꾸면 전체 테마가 바뀌도록 관리되고 있으니, 이 구조를 깨지 않도록 색상 변수명을 의미 단위로 정리해서 추가/수정해 주세요.

## 전체 톤앤매너
- 좌측에 아이콘만 있는 다크 네이비(`--color-navy-dark`, 예: #0B1437 계열) 세로 사이드바 유지, 폭은 축소된 형태
- 메인 배경은 밝은 그레이/화이트(#F5F6FA 계열)
- 우측 상단 배경에 대각선으로 잘린 네이비/블루 장식 블록 추가 (배경 레이어로, 콘텐츠와 겹치지 않게)
- 전체적으로 파란색 계열(Primary Blue #2F6FED ~ #4E7FFF)을 포인트 컬러로 사용

## 상단 헤더
- 좌측 검색창(둥근 모서리, 연한 회색 배경)
- "Week" 드롭다운 필터
- 우측 알림 벨 아이콘, 사용자 아바타 + 이름 + 드롭다운 화살표
- 아이콘은 얇은(outline) 스타일로 통일

## 페이지 타이틀 영역
- "Dashboard" 제목은 세미볼드, 24~28px
- 옆에 날짜 범위 선택 필드(캘린더 아이콘 + "14 Jan, 2020 - 20 Jan, 2020" 형식, 둥근 테두리 박스)

## KPI 요약 행 (기존 지표 값과 위치는 유지)
- 각 지표를 "라벨 + 큰 숫자 + 작은 스파크라인 미니 차트 + 증감률 배지(초록/빨강, 화살표 아이콘)" 형태로 통일
- 배경 없이 심플하게, 구분선 정도만

## 카드 스타일 (모든 차트/테이블 컨테이너 공통)
- 흰색 배경, border-radius 12~16px, 은은한 box-shadow (`0 2px 8px rgba(0,0,0,0.05)` 정도)
- 카드 내부 패딩 넉넉하게(20~24px)
- 카드 헤더: 좌측 제목(14~16px, semi-bold), 우측 필터 토글(Week/Month/Year 버튼 그룹 또는 점 3개 메뉴 아이콘)
- 카드 간 간격은 그리드로 균일하게(가로 2열 배치 유지)

## 차트 컬러 스킴 (기존 차트 종류 그대로, 색상만 교체)
- 메인 포인트 컬러: 진한 블루(#2F6FED)
- 보조 컬러: 하늘색(#8FC1FF), 네이비(#1B2A63)
- 영역/막대 차트는 블루 계열 단색 또는 톤온톤 조합
- 도넛/파이 차트는 블루-네이비-하늘색 계열로 구성, 중앙에 퍼센트 텍스트 강조
- 라인 차트는 얇은 블루 라인 + 포인트 마커

## 테이블 (Most Visited Pages 등)
- 헤더 행은 연한 회색 텍스트, 얇은 구분선
- 각 행에 트렌드 미니 스파크라인 컬럼 유지
- 정렬 화살표 아이콘 추가

## 리스트형 카드 (Social Media Traffic 등)
- 채널명 + 가로 바 그래프(블루 계열) + 수치 형태 유지, 색상만 통일

## 하단 푸터
- 다크 네이비 배경, 로고 + 4개 컬럼 링크 리스트 + 소셜 아이콘 + 앱스토어 배지
- 텍스트는 밝은 회색/화이트, 링크 hover는 블루

## 타이포그래피
- Sans-serif 폰트(기존 폰트 유지)
- 숫자 강조는 semi-bold~bold, 라벨/설명은 regular, 연한 회색
