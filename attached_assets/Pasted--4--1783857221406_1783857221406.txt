# 차트 디자인 상세 스펙 (기존 프롬프트에 추가)

> 이 문서는 앞서 전달한 "대시보드 디자인 패턴 변경 요청"의 4번 항목(차트 색상 통일)을 세부적으로 확장한 내용입니다. **차트 종류·데이터·축 범위·표시되는 값은 절대 변경하지 말고, 아래 스타일 속성만 적용**해주세요. 사용 중인 차팅 라이브러리(Recharts, Chart.js, ECharts, D3 등)에 맞춰 동일한 시각적 결과가 나오도록 속성값을 매핑해주세요.

---

## 1. 라인/영역 차트 (Trend, 방문자 추이 등)
- **라인 색상**: 메인 시리즈 `#4a7fd4`, 보조 시리즈 `#f0876b`
- **선 굵기(stroke-width)**: 2.5px
- **선 형태**: 완만한 곡선(monotone/curved), 꺾이는 직선(linear) 금지
- **영역 채우기(area fill)**: 라인 하단에 세로 그라데이션
  - 상단: 해당 색상의 25% 투명도
  - 하단: 해당 색상의 0% 투명도 (완전 투명)
- **데이터 포인트(dot)**: 기본 상태에서는 숨김, hover 시에만 반지름 4~5px 원으로 표시하고 흰색 테두리 2px 추가
- **그리드 라인**: 가로선만 표시, 색상 `rgba(0,0,0,0.05)`, 세로 그리드는 제거
- **축 라벨**: font-size 11~12px, color `#8b96ab`, 축 자체 라인은 제거(borderless axis)
- **툴팁**: 흰 배경 + `box-shadow: 0 4px 16px rgba(0,0,0,0.1)` + border-radius 8px, 다크 텍스트

## 2. 도넛 차트 (달성률, 비율 지표)
- **링 두께**: 전체 반지름의 15~18% 수준 (얇고 여백이 많은 스타일)
- **색상**: 진행/완료분 `#4a7fd4`, 미달성/배경분은 `#e8ecf4` (연회색, 코랄 아님)
- **모서리**: 링 끝을 라운드 처리(strokeLinecap: round)
- **중앙 텍스트**: 퍼센트 숫자를 크고 굵게(font-size 28~32px, weight 700, color navy), 바로 아래 작은 회색 라벨 추가
- **애니메이션**: 0%에서 목표값까지 부드럽게 채워지는 진입 애니메이션(선택 사항)

## 3. 막대 차트 (일별/카테고리별 비교)
- **막대 색상**: 단일 색상 `#4a7fd4` 통일 (카테고리 구분이 필요한 경우만 코랄 병행)
- **막대 상단 모서리**: border-radius 4~6px (상단만 라운드, 하단은 각짐)
- **막대 너비 대비 간격**: 막대:간격 비율 약 6:4 (너무 붙지 않게)
- **hover 상태**: 막대 색상을 10% 어둡게 하거나 옅은 그림자 추가
- **기준선(baseline)**: 하단 축선 제거하거나 매우 옅게(`rgba(0,0,0,0.06)`)
- **값 라벨**: 막대 위에 직접 표시할 경우 font-size 11px, color `#1a2744`

## 4. 게이지/스피드미터 차트 (달성률 반원형 지표)
- **트랙(배경) 색상**: `#e8ecf4`
- **진행 색상**: `#4a7fd4` 단색, 또는 낮은 구간은 코랄 → 높은 구간은 블루로 그라데이션 전환(선택 사항)
- **트랙 두께**: 반지름의 12~15%
- **끝 모양**: 라운드 캡(strokeLinecap: round)
- **중앙/하단 숫자**: 크고 굵게, navy 컬러
- **바늘(needle) 사용 시**: 얇은 라인 + 끝에 작은 원형 포인트, 색상은 navy

## 5. 공통 규칙 (모든 차트 공통 적용)
- **폰트**: 차트 내 모든 텍스트는 대시보드 본문과 동일한 폰트 패밀리 사용
- **범례(legend)**: 있는 경우 원형 마커 + 텍스트 조합, 상단 또는 우측 정렬, font-size 12px
- **애니메이션 duration**: 진입 시 400~600ms, easing은 ease-out
- **반응형**: 카드 크기 변화에 따라 차트가 자동 리사이즈되도록 유지 (기존 로직 유지, 스타일만 위 규칙 적용)
- **색상 하드코딩 금지**: 가능하면 앞서 정의한 CSS 변수(`--color-primary-blue`, `--color-accent-coral` 등)를 차트 설정에서도 참조하도록 구성해 이후 테마 변경이 쉽게 되도록 처리
